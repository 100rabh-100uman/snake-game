## 📖 About The Game

Ek **classic Snake game ka modern version** — jisme realistic snake animations, smooth gameplay, sound effects aur mobile touch controls sab kuch hai! Desktop par keyboard se aur mobile par **Free Fire style dynamic joystick** se khelo.

## ✨ Features

### 🎮 Gameplay
- **Realistic Snake** — animated eyes, forked tongue, scale pattern aur gradient body ke saath
- **3 Difficulty Levels** — 🟢 Easy | 🟡 Medium | 🔴 Hard (speed change hoti hai)
- **Score System** — har fruit 🍎 = 10 points
- **High Score** — localStorage me save hota hai (refresh karne par bhi nahi mitta)
- **Particle Effects** — fruit khane par explosion effect 💥
- **Pause / Resume / Exit** support

### 🔊 Sound Effects
- Fruit khane par satisfying crunch + pop sound
- Game Over par custom `gameover.mp3`
- **Milestone Sound!** — 70 points (7 fruits) complete karne par `milestone.mp3` play hota hai 🎉
- Sound on/off toggle button

### 📱 Mobile Support
- **Free Fire Style Dynamic Joystick** — screen par kahin bhi touch karo, wahi se joystick dikhta hai
- Drag direction me snake move hota hai
- Gameplay ke time scroll lock (upar-neeche scroll nahi hoga)
- Fully responsive layout — mobile stats section neeche dikhta hai

### 🎨 Visual UI
- Animated glowing background particles ✨
- Neon gradient theme (cyan/green glow)
- Pulsing apple with stem & leaf 🍎
- Live score bar during gameplay
- Smooth overlays for Start & Game Over screens

## 🕹️ Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move Snake | ⬆️⬇️⬅️➡️ Arrow Keys / `W A S D` | 🕹️ Dynamic Joystick |
| Pause / Resume | `SPACE` | ⏸ PAUSE Button |
| Exit Game | `ESC` | 🚪 EXIT Button |
| Start Game | `ENTER` / ▶ START Button | ▶ START Button |

## 🚀 How To Run

1. Repository clone karo:
   ```bash
   git clone https://github.com/100rabh-100uman/snake-game.git
   ```
2. Project folder me jao:
   ```bash
   cd snake-game
   ```
3. `index.html` ko browser me open karo — bas! Game start ho jayega 🎮

> 💡 **Tip:** GitHub Pages se directly bhi khel sakte ho — [Live Demo](https://100rabh-100uman.github.io/snake-game/)
