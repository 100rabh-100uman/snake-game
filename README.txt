========================================

HOW TO ADD YOUR CUSTOM GAME OVER SOUND
========================================

1. Open this YouTube video in your browser:
   https://youtube.com/shorts/9ufVi9TqeCg?si=sI_AaShITR-_a9vI

2. Use any YouTube to MP3 converter website (like:
   - y2mate.com
   - ytmp3.cc
   - onlinevideoconverter.com
   Search "youtube to mp3 converter" on Google)

3. Paste the YouTube link and convert it to MP3 format

4. Download the MP3 file

5. Rename the downloaded file to:  gameover.mp3

6. Place the gameover.mp3 file in this same folder:
   (Snake Game JS folder - where index.html is located)

7. Refresh the game in your browser

That's it! Now when the snake dies, your custom sound will play!

NOTE: If the gameover.mp3 file is not found, the game will
automatically use the built-in game over sound effect.
